# Data provenance

Saverio Vito (2008). Air Quality. UCI Machine Learning Repository. DOI: https://doi.org/10.24432/C59K5F

Source: https://archive.ics.uci.edu/dataset/360/air%2Bquality

The original UCI archive was downloaded on 2026-10-17; hashes and byte size are in manifest.json. No source values were edited. Decimal commas are parsed numerically; -200 is treated as missing as documented by UCI. Empty rows are excluded, and means use valid values only. No imputation, prediction, or causal inference is performed.

UCI's current page lists CC BY 4.0, but its dataset description also contains a research-only/noncommercial restriction. Because these notices conflict, the release package excludes the raw CSV. Reproduction requires an explicit download from the source and is presented for research evaluation, not commercial deployment or a redistribution license decision. Code's MIT license does not cover third-party data.

Observed CSV: 9,357 populated rows, 114 empty rows, timestamps 2004-03-10 through 2005-04-04. UCI describes 9,358 instances and a different end month. The report preserves file evidence rather than adjusting values to the description. This is historical field-sensor data, not a live sensor feed.
